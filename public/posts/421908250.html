译者注：文中的 API 指的是 Application Programming Interface，即应用程序接口。

常青笔记[1]划分合理，命名恰当的话，得到的标题就是对笔记内容的抽象。由此一来，整篇笔记讨论的概念可以用这个抓手来引用（见概念抓手，由 Alexander 提出[2]）。实际上，标题寥寥数语便能勾勒出笔记内容轮廓：每天都在笔记中构筑概念并改进笔记的「API」，将大量笔记提炼抽象为单则笔记的能力，也会更上一层楼（例如，情景体验成为大众媒体时蕴藏极大潜力[3]，常青笔记写作是知识工作的基本单位[4]）。

一些有效的笔记「API 设计」技巧：关注点分离（常青笔记应该是原子化的[5]），精准标题（笔记标题建议使用完整的句子，避免模糊主张[6]），和正面阐述（笔记标题建议正面表述，以促进说理系统化[7]）。

常青笔记写作是知识工作的基本单位↗

作者把知识工作中的核心产出视为日常写作的常青笔记：笔记不仅保存或打草稿，更应帮助积累洞见、沉淀阅读成果，并为后续写作提供材料。因此，“更好地记笔记”只是表面说法，真正目标是更好地思考。

常青笔记应该是原子化的↗

Andy Matuschak 主张常青笔记最好围绕单一主题写得完整，以便发现新想法、建立清楚链接并复用论证；笔记过于宽泛会使链接指向不明，切得太碎又会削弱内聚。他把这种取舍类比为软件工程中的关注点分离，并称笔记标题类似 API。
